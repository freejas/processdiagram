# Example scripts

All examples use data distributed with R or files bundled with `processdiagram`.
They are intended to demonstrate the API rather than make substantive causal
claims about the example datasets.

- `00_native_quick_start.R` is fully runnable with `processdiagram` alone.
- `01` through `04` use base-R datasets but require PROCESS to have been sourced
  separately because PROCESS itself is not redistributed by this package. Download PROCESS from <https://afhayes.com/download.html>. The wrapper supports PROCESS for R 4.1 and 5.0 for the supported mediation models.
- `05_save2_import.R` is fully runnable using the bundled PROCESS 5 fixture.
